# Kris Pablo — fixed portfolio code

## Open the website
Extract the ZIP. Open `index.html` in your browser, or open this folder in VS Code and preview with Live Server. No installation or build is required.

## File structure
- `index.html` — formatted main page, with section comments.
- `style.css` — formatted pink theme, responsive layouts, and animations.
- `script.js` — portfolio rendering, scroll animations, and pointer effects.
- `projects.js` — edit the six project titles, categories, URLs, and optional images here.
- `portfolio.html` — coming-soon page for empty portfolio slots.
- `resume-image-000.jpg` — profile photo.
- `kris-pablo-resume.pdf` — resume.

## Fixes
Removed Markdown escape backslashes from HTML tags, URLs, email addresses, and `_blank` targets. Restored valid HTML, readable indentation, and clear sections. Included the supporting files referenced by the pasted HTML so the site runs as a complete project. Preserved its content and design.

Portfolio links use `target="_blank"` and `rel="noopener noreferrer"`. A blank project URL opens the local coming-soon page. Google Fonts requires internet; fallback fonts work offline.
